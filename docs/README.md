# 项目文档

本目录只保留课程交付和后续维护需要的正式文档。

| 文档 | 内容 | 演示时用途 |
|---|---|---|
| [requirements.md](requirements.md) | 项目目标、角色、功能和非功能要求 | 说明“为什么做、需要做什么” |
| [architecture.md](architecture.md) | 系统架构、核心流程、部署和安全设计 | 说明“系统怎么实现” |
| [api.md](api.md) | Backend 与 AI 服务接口索引 | 联调或答辩追问时查阅 |
| [testing-and-acceptance.md](testing-and-acceptance.md) | 测试结果、验收流程、已知限制 | 证明项目可运行、闭环可验证 |
| [collaboration.md](collaboration.md) | 三人分工、分支和提交规范 | 展示小组协作方式 |
| [test-evidence/](test-evidence/) | 关键业务流程截图 | 作为测试报告的辅助证据 |

## 推荐阅读顺序

1. 根目录 `README.md`：启动项目并了解演示流程。
2. `requirements.md`：核对任务目标。
3. `architecture.md`：理解前端、后端、AI 和基础设施关系。
4. `testing-and-acceptance.md`：按验收步骤演示。
5. `api.md`：需要查看接口细节时使用。

实验过程截图、浏览器 snapshot、临时网络日志和失败调试文件不属于正式交付文档，不再放入仓库根目录。
